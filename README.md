# TOEIC – Điền từ đồng nghĩa

## Cách sử dụng
1. Tải `index.html` lên một repository GitHub.
2. Mở **Settings → Pages**.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn branch `main`, folder `/ (root)`, rồi nhấn **Save**.
5. Chờ GitHub Pages tạo website và mở đường dẫn được cung cấp.

Website chạy hoàn toàn bằng HTML/CSS/JavaScript, không cần cài đặt hay backend.

## Cách học
- Mỗi nhóm từ đồng nghĩa trong tài liệu là một câu hỏi.
- Website hiển thị từ đầu tiên và nghĩa tiếng Việt.
- Điền các từ/cụm từ còn lại; gợi ý là chữ cái đầu của từng từ.
- Nhấn **Kiểm tra câu này** để xem ô đúng/sai.
- Có thể hiện đáp án, xóa câu trả lời, lọc theo chủ đề hoặc làm câu hỏi ngẫu nhiên.

Dữ liệu được lấy từ tài liệu `TOEIC_tu_dong_nghia.docx` (257 nhóm).
